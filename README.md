## Liar's BarGame
在cctweaked中运行的骗子酒馆游戏Liar'sBar的模拟，需要一台主服务器电脑与四台游戏机电脑，并为每台计算机配备无线调制解调器，为主机配备一枚扬声器。在服务器程序启动后，游戏机程序会自动寻找对局并加入。游戏具有适配CraftOS或大尺寸屏幕的图形GUI。
## CoToManager
一个模仿Create Mod中工厂仪表功能的程序，能指定原料容器和目标容器种类、需要补齐的物品名称和数量，自动将目标容器内的物品补齐至设定值。鉴于具体设置每个容器详细名称非常不便，只做容器类别的区分。目标容器和原料容器需要不同种类。
